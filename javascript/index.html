Go2 WebXR Control

Enter AR mode to control your Go2 robot with hand controllers and command menu. The background will show passthrough (real world) instead of black.

  • Left Stick: Strafe left/right and move forward/backward
  • Right Stick: Rotate left/right
  • B/Y Button: Toggle command menu
  • Trigger: Select menu items (point and click)
  • Connection: Auto-connects when VR starts

Command Menu: Basic commands, Tricks (jump, flip, dance), Movement settings
